# Playground

1. Run `./gradlew runPluginCLion`.
2. Build `playground` or `reflection_preview`.
3. In `reflection.slang`, try **Find C++ Usages**, **C++ View**, or **Rename** on `PlaygroundMaterial`.

Needs Slang SDK 2026.22+. Logs: `./gradlew playgroundLogCLion`.

Run `runPluginCLion` again to bring the open playground forward and reload it once its edits are saved.
