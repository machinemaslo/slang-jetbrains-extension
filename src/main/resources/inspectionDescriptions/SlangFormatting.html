Reports files whose layout differs from the selected formatter's output. Prefers clang-format when available, using the project's .clang-format file or Slang code-style fallback. Otherwise uses the native JetBrains formatter with the Slang code-style settings. The Reformat file quick fix formats the current document in an undoable operation. Checks run in the background on project files up to 1 MB. Native checks require no external executables.
